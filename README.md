Small browser toys and experiments by Bogdan Deaky.

**Play in the browser** — no install, no build step.

| Project | Link | Blurb |
|---------|------|-------|
| [Tiny Chaos Factory](./tiny-chaos-factory/) | [Play](./tiny-chaos-factory/index.html) | Build a dumb machine. Watch it become soup. |

## GitHub Pages

If Pages is enabled for this repo, the site root should show the [landing page](./index.html).

Direct game URLs look like:

- `/tiny-chaos-factory/` — Tiny Chaos Factory

## itch.io

Each game gets its own itch page. Zip **only that game's folder** (with `index.html` at the zip root).

## Add a new project

1. Create a folder: `mini-projects/my-new-toy/`
2. Put a self-contained `index.html` (+ assets) inside
3. Add a row to this README and to [index.html](./index.html)

Keep each game folder standalone so links and itch zips stay simple.
